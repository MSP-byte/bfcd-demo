# Criterio de Storage

Bucket: `bfcd-archivos`.

Estructura prevista:
- `revistas-bap/`
- `revistas-tecnicas/`
- `reglamentos-itinerarios/`
- `fotos-antiguas/`
- `material-rodante/`
- `miniaturas/`

Convención sugerida: nombres en minúsculas, sin espacios ni tildes; prefijo con código BFCD cuando corresponda.

Para la mini demo el bucket es público para lectura. La escritura desde navegador anónimo no está habilitada.
